# stell-llm

Собственный рантайм инференса LLM для NVIDIA Tesla V100 (SM70, SXM2, NVLink).

Идея: **любая модель** (dense и MoE) + **tiering весов VRAM → RAM → NVMe** (как в project-maya)
+ **Volta-ядра и NVLink-параллелизм** уровня 1Cat-vLLM, без недостатков обоих прототипов.

Дорожная карта, архитектура и критерии приёмки: [PLAN.md](PLAN.md).

Статус: **планирование**. Подход — полноценный продукт с первого дня: целевая архитектура вся,
модули — параллельными потоками, без MVP-фаз. Код модулей ещё не реализован; интерфейсные
контракты зафиксированы (см. ниже).

## Сборка

> ⚠️ Ниже — **план** сборки, зафиксированный в ADR-07. Сборка ещё не реализована
> (в репозитории нет `CMakeLists.txt` и исходников); команды приведены как целевые
> и не проверены. Обновить этот раздел по мере появления кода.

- **CPU-конфигурация (локально, без GPU)** — обязательный путь CI и юнит-тестов:
  планировщик, реестр моделей, лоадеры, эмулятор комм-паттернов (ADR-10 §4),
  tier-политика на RAM/NVMe-файлах (план):
  ```bash
  cmake -S . -B build/cpu -DCMAKE_BUILD_TYPE=Release
  cmake --build build/cpu -j
  ctest --test-dir build/cpu --output-on-failure
  ```
- **CUDA-конфигурация (целевой сервер, SM70)** — только на сервере
  `ssh -p 2214 192.168.1.114` с учётом совмещения (чужой процесс держит
  ~21–30 GB VRAM на каждой V100 — не мешать ему; план):
  ```bash
  cmake -S . -B build/cuda -DCMAKE_BUILD_TYPE=Release \
        -DCMAKE_CUDA_ARCHITECTURES=70 -DSTELL_WITH_CUDA=ON
  cmake --build build/cuda -j
  ```

## Запуск API и дашборда

> ⚠️ План: один Python-процесс (FastAPI, тонкий control-plane) на порту 8080
> с in-process движком `libstell_core.so` (ADR-11): `/v1/chat/completions`,
> `/v1/messages`, `/health`, `/metrics`. Не реализовано — команды появятся
> в этом разделе по мере готовности serve-слоя.

## Известные ограничения

- Кода модулей и тестов пока нет; всё, что описано в PLAN.md §4 и в
  [docs/design/](docs/design/README.md), — целевая архитектура, не реализованное.
- Multi-GPU CUDA-прогоны — только на целевом сервере (см. выше), с ограничением
  по совмещению с чужим процессом.
