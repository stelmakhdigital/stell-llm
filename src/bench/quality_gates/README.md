# quality-gates (каркас, PLAN.md §5)

Состав:

- `schema.json` — схема результатов гейтов + описание датасетов;
- `data/gsm8k_32.jsonl` — ЗАГОТОВКА (синтетические 32 задачи, реальный
  поднабор GSM8K подключается после интеграции весов/движка);
- `data/humaneval_32.jsonl` — ЗАГОТОВКА (синтетические 32 задачи);
- `data/ppl_text.txt` — фиксированный текст для PPL (менять запрещено между
  версиями: сравнение версий по §5).

Прогон без модели честно помечается `pending=true`
(`stell_bench.quality_gates.run_gates_pending`); значения accuracy/PPL
появятся только после интеграции реального движка и весов.
