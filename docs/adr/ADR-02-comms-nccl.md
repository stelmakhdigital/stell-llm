# ADR-02: Коммуникации — NCCL поверх NVLink; P2P DMA для tiering

- **Статус:** Принято (PLAN.md §3)
- **Связано:** ADR-08 (tiering-копирования), ADR-10 (параллелизм)

## Контекст

Нужны TP/EP по NVLink (SXM2) между 4–8×V100 и копирования весов VRAM ↔ RAM ↔ NVMe.

## Решение

- Multi-GPU комм-паттерны (TP/EP/PP) — поверх **NCCL** (детали интерфейса — ADR-10).
- Tiering-копирования — **CUDA P2P DMA + pinned RAM staging** (интерфейс — ADR-08).

## Альтернативы

- **Самописные коллективные копирования** — не нужны: NCCL зрел и уже
  оптимизирован под NVLink; свой стек только добавит ошибки и расходы на отладку.

## Последствия

Зависимость `libnccl` на целевом сервере (подтверждена). CPU-пути параллелизма
тестируются через эмулятор комм-паттернов (ADR-10) без NCCL и GPU.
