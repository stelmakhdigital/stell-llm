# ADR-07: Сборка — CMake; CI GitHub Actions (CPU-пути без GPU)

- **Статус:** Принято (PLAN.md §3)
- **Связано:** README (раздел «Сборка», помечен как план)

## Контекст

CUDA-сборка возможна только на целевом сервере (SM70), локальная машина — CPU-only.
Тесты и CI должны работать без GPU.

## Решение

- Система сборки: **CMake** (два конфига: CPU и CUDA-SM70).
- CI: **GitHub Actions** на CPU-путях: планировщик, реестр моделей, лоадеры
  (на CPU-файлах), эмулятор комм-паттернов, tier-политика на RAM/NVMe-файлах.
- CUDA-сборка/прогоны — только на целевом сервере `ssh -p 2214 192.168.1.114`
  с учётом совмещения (чужой процесс держит ~21–30 GB VRAM на каждой V100).

## Альтернативы

- **Meson/Bazel** — без выгод: у команды уже CMake-профиль; зависимости простые.

## Последствия

Каждый модуль обязан иметь CPU-исполнимый путь (см. ADR-08…ADR-11: эмуляции
комм-паттернов, RAM/NVMe-тиры без CUDA) — это условие тестируемости в CI.
