# ADR-04: KV-кеш — FP16 базово; E4M3-8бит опционально (софтовый квант)

- **Статус:** Принято (PLAN.md §3)
- **Связано:** ADR-08 (роль kv в тензорных группах), ADR-09 (описание модели)

## Контекст

V100 (SM70) не имеет нативного FP8. При этом длинный контекст упирается в объём KV-кеша.

## Решение

- База: KV-кеш **FP16**.
- Опция: **E4M3 8-битный софтовый квант** (scale per-block/per-tensor), включается
  только по решению калибровщика (арбитр — PLAN.md §4, поток E) и/или конфигу.
  FP8 «нативно» на V100 недоступен — только эмуляция через dequant-ядра.

## Альтернативы

- **Нативный FP8 KV** — физически недоступен на SM70.

## Последствия

Роль `kv` в тензорных группах (ADR-08) несёт dtype (`F16` или `E4M3`), и tiers
переносит KV-блоки без знания про модель. Включение кванта фиксируется в бенч-отчётах
(поле KV-dtype в контракте PLAN.md §5).
