# ADR-06: API — один процесс на порту 8080: /v1/chat/completions + /v1/messages

- **Статус:** Принято (PLAN.md §3)
- **Связано:** ADR-11 (контракт engine ↔ serve)

## Контекст

Нужны OpenAI- и Anthropic-совместимые API со стримингом SSE и tool-calls,
без отдельного прокси и без размножения процессов/портов.

## Решение

Один serve-процесс (Python control-plane) на **порту 8080**, маршруты:

- `/v1/chat/completions` (OpenAI-совместимый, включая SSE-стриминг и tool-calls);
- `/v1/messages` (Anthropic-совместимый);
- `/health`, `/metrics` (health/метрики; см. ADR-11);
- CORS — включён (политика по умолчанию: разрешённые origin через конфиг).

Формат stream-событий и способ встраивания engine — контракт ADR-11.

## Альтернативы

- **Отдельный прокси перед API** — не нужен: лишний hop и ещё один процесс.

## Последствия

Единая точка портов: дашборд и бенчмарк-харнесс общаются с тем же процессом.
Планировщик engine обязан обслуживать ≥8 параллельных сессий (continuous batching) — ADR-11.
