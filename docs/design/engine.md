# engine — дизайн-документ (заготовка)

> Статус: заготовка. Модуль не реализован. Контракты: ADR-08, ADR-09, ADR-10, ADR-11.

## Уточнения контракта (round 1, T-20261017200354)

- Слой→группы: engine — единственный вызывающий `set_plan` + `set_layer_map`
  (пара, «холодная» дисциплина, до переснятия графа); `layout_version` —
  детерминированный хэш состава плана (`ExecutionPlan`), сверяется
  `DecodeExecutor` — см. ADR-08 «Уточнение».
- Мета шага: ранг 0 рассылает 8×F32 слотов через `allgather` (ADR-10 «Уточнение»).
- Sampling: «T=1» = `temperature=1.0` (не greedy); greedy — отдельный явный
  режим golden-контракта (ADR-09 «Уточнение»).

## Объём (из PLAN.md §4, поток A)

- Планировщик continuous batching на ≥8 сессий; пулы слотов фиксированного размера.
- CUDA Graph по константной разметке + eager-фолббек (ADR-05).
- Спекулятивный контур: драфт + FP32-верификация + автоотключение по калибровке.
- KV-streaming для длинного контекста.

## Готовность (критерии PLAN.md §4)

- Ядра проходят операторные replay-тесты; dense в 1 GPU и MoE с фиксированным пулом
  экспертов в 1 GPU через engine; CPU-пути тестируются без GPU.
