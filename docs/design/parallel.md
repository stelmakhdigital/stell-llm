# parallel — дизайн-документ (заготовка)

> Статус: заготовка. Модуль не реализован. Контракт: ADR-10 (интерфейс, CPU-эмуляция).

## Уточнения контракта (round 1, T-20261017200354)

- Мета шага (ADR-10 «Уточнение»): рассылка — фиксированный F32-пейлоад
  (8 слотов × float = 32 байта: `[шаг, размер батча, резерв…]`) через обычный
  `allgather(CommDType::F32)`; отдельный `CommDType::Meta` отклонён —
  parallel остаётся семантически нейтральным, формат слотов знает только engine.

## Объём (из PLAN.md §4, поток C)

- NCCL TP (dense), EP-шардирование экспертов по NVLink, PP для dense > VRAM.
- Комбинированные схемы PP×TP / PP×EP; KV-streaming между узлами.
- Бенчмарки масштабирования: TP4 dense ≥3.2× от TP1.

## Готовность

- GLM-класс на 4–8×V100-SXM2 проходит TP/EP-контуры; CPU-пути комм-паттернов
  тестируются локально без NCCL/GPU (ADR-10 §4).
